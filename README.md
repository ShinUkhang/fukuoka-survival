# 후쿠오카 서바이벌 🦆🍜

후쿠오카 여행 컨셉의 3D 카툰풍 로그라이크 서바이벌 웹게임. 좀비 비둘기 무리가 몰려온다! 후더덕과 함께 후쿠오카 여행에서 살아남아라!

- 🕹️ 이동: WASD / 방향키 / 모바일 조이스틱 (공격은 자동)
- 🍜 무기 6종: 하카타 라멘포, 멘타이코 스트라이크, 신칸센 스파크, 궤도 우메가에모찌, 카키고오리, 텐만구 레이저 (각 5레벨)
- 💎 적을 처치하고 별 젬을 모아 레벨업 → 3장 중 1장 선택
- 👹 90초마다 비둘기왕 보스 출현
- 🍜 라멘(체력 회복), 🧲 자석(젬 흡수) 픽업
- 🗺️ 맵 곳곳에 후쿠오카 랜드마크: 하카타역, 다자이후 도리이·텐만구, 나카스 야타이, 고쿠라성, 모지코 레트로, 규슈국제고
- 🏆 로컬 최고 기록 저장, WebAudio 효과음

## 실행

`index.html`을 브라우저로 열면 바로 실행된다. (단일 파일, 외부 의존성 없음)

## 테스트

- Node 헤드리스 로직 테스트 63/63 PASS
- Chromium 실제 렌더링 확인 (랜드마크 4곳, 타이틀/플레이/레벨업/게임오버)
